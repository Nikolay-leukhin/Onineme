# Spec Delta

## MODIFIED Requirements

### Requirement: Схема БД существует заранее
Бот SHALL при запуске создавать в PostgreSQL недостающие таблицы пользователей, тайтлов и подписок. Существующие таблицы и данные MUST NOT удаляться или изменяться при этом.

#### Scenario: Запуск на пустой БД
- **WHEN** бот запускается на PostgreSQL без таблиц
- **THEN** бот создаёт таблицы пользователей, тайтлов и подписок и продолжает работу

#### Scenario: Запуск на заполненной БД
- **WHEN** бот запускается на PostgreSQL, где таблицы уже есть и содержат данные
- **THEN** данные сохраняются без изменений

## ADDED Requirements

### Requirement: Сбой фонового цикла не останавливает бота
Ошибка в итерации синхронизации каталога или проверки обновлений (включая недоступность или изменение разметки AnimeGo) SHALL записываться в лог, после чего цикл MUST продолжить работу по своему расписанию. Процесс бота и обработка сообщений пользователей MUST NOT прекращаться из-за такой ошибки.

#### Scenario: AnimeGo недоступен
- **WHEN** при синхронизации каталога AnimeGo не отвечает или возвращает ошибку
- **THEN** ошибка записана в лог, бот продолжает отвечать на команды, и синхронизация повторяется позже

#### Scenario: Изменилась разметка AnimeGo
- **WHEN** проверка обновлений не может разобрать страницу AnimeGo
- **THEN** ошибка записана в лог, а следующая проверка выполняется по расписанию

### Requirement: Запросы к источнику не блокируют диалоги
Каждый запрос к AnimeGo SHALL ограничиваться таймаутом, а обход страниц списка — максимальным числом страниц. Ожидание ответа источника MUST NOT задерживать ответы бота пользователям.

#### Scenario: Медленный ответ источника
- **WHEN** AnimeGo отвечает дольше таймаута
- **THEN** запрос прерывается с ошибкой, которая обрабатывается как сбой итерации цикла

#### Scenario: Команда во время загрузки страницы
- **WHEN** бот ждёт ответа AnimeGo и пользователь отправляет /help
- **THEN** бот отвечает справкой, не дожидаясь ответа AnimeGo

#### Scenario: Источник не сообщает о последней странице
- **WHEN** AnimeGo на каждую страницу списка отвечает без признака конца списка
- **THEN** обход прекращается по достижении максимального числа страниц
