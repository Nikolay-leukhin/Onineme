# Proposal

## Why

Проект давно не запускался: нет способа поднять бот и его хранилища одной командой, зависимости зафиксированы под Windows и конфликтуют между собой (`bson` против `pymongo`, `psycopg2` требует сборки), схема PostgreSQL нигде не создаётся, а падение парсера AnimeGo роняет весь процесс бота. Нужно «реинкарнировать» проект так, чтобы все сервисы стабильно поднимались в Docker — как основа для последующей полной переработки.

## What Changes

- Добавляется контейнерный запуск: образ бота и `docker compose` со службами бота, PostgreSQL и MongoDB, томами для данных и проверками готовности хранилищ.
- Зависимости приводятся к устанавливаемому в Linux-контейнере набору (убираются Windows-only и конфликтующие пакеты, `psycopg2` заменяется на бинарную сборку).
- **BREAKING**: бот при запуске сам создаёт недостающие таблицы PostgreSQL (вместо требования «схема существует заранее»).
- Фоновые циклы (синхронизация каталога и проверка обновлений) перестают ронять процесс: ошибка итерации логируется, цикл продолжает работу. Запросы к AnimeGo получают таймаут, лимит страниц и не блокируют обработку сообщений.
- README переписывается (UTF-8) с инструкцией запуска через Docker.

Вне рамок: починка самого парсинга AnimeGo (разметка сайта, вероятно, изменилась), изменения пользовательских сценариев бота, CI/деплой на сервер.

## Capabilities

### New Capabilities
- `container-deployment`: запуск бота вместе с PostgreSQL и MongoDB одной командой в контейнерах, сохранность данных между перезапусками, порядок старта и автоперезапуск.

### Modified Capabilities
- `bot-runtime`: создание схемы БД при запуске вместо требования её предварительного наличия, устойчивость процесса к сбоям фоновых циклов.

## Impact

- Новые файлы: `Dockerfile`, `docker-compose.yml`, `.dockerignore`, `.env.example`.
- Код: `main.py`, `external_services/api_service.py`, `life_cycles/collection/collection_manager.py`, `life_cycles/update/update_controller.py`.
- Зависимости: `requirements.txt` (удаление `bson`, `win32-setctime`, `pip`/`setuptools`/`wheel`; `psycopg2` → `psycopg2-binary`).
- Документация: `README.md`.
- Требуется установленный Docker с Compose v2; локальный `.env` с `TELEGRAM_TOKEN`.
