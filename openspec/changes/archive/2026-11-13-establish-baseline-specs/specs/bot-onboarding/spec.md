# Spec Delta

## Purpose

Точка входа пользователя в бота: знакомство через /start с регистрацией, справка /help, меню команд и реакция бота на сообщения, не относящиеся ни к одному сценарию.

## ADDED Requirements

### Requirement: Регистрация пользователя по /start
По команде /start бот SHALL зарегистрировать пользователя по идентификатору чата вместе с его username, если такой пользователь ещё не зарегистрирован. Отсутствие username MUST NOT препятствовать регистрации. Повторный /start MUST NOT создавать второго пользователя.

#### Scenario: Первый /start
- **WHEN** незарегистрированный пользователь отправляет /start
- **THEN** бот регистрирует пользователя с идентификатором его чата и его username

#### Scenario: Повторный /start
- **WHEN** зарегистрированный пользователь отправляет /start
- **THEN** бот не создаёт нового пользователя и отвечает приветствием

#### Scenario: Пользователь без username
- **WHEN** пользователь без username отправляет /start впервые
- **THEN** бот регистрирует его с пустым username

### Requirement: Приветствие по /start
В ответ на /start бот SHALL отправить приветственное сообщение, объясняющее назначение бота и указывающее на команды /search, /choose и /help.

#### Scenario: Ответ на /start
- **WHEN** пользователь отправляет /start
- **THEN** бот отвечает приветствием, в котором упомянуты /search, /choose и /help

### Requirement: Справка по /help
По команде /help бот SHALL отправить статический список команд /mysubs, /start, /search, /choose с кратким описанием каждой.

#### Scenario: Ответ на /help
- **WHEN** пользователь отправляет /help
- **THEN** бот отвечает списком команд /mysubs, /start, /search, /choose с описаниями

### Requirement: Меню команд
При запуске бот SHALL публиковать в Telegram меню из пяти команд: start, help, mysubs, choose, search, каждую с описанием на русском языке.

#### Scenario: Меню после запуска
- **WHEN** бот запущен и пользователь открывает меню команд в Telegram
- **THEN** в меню доступны команды start, help, mysubs, choose, search

### Requirement: Сообщения вне сценариев игнорируются
Текстовое сообщение, которое не является известной командой и не ожидается активным сценарием, бот SHALL оставлять без ответа.

#### Scenario: Произвольный текст без активного сценария
- **WHEN** пользователь без активного сценария отправляет произвольный текст
- **THEN** бот ничего не отвечает
