# Proposal

## Why

У бота нет ни одной спецификации, поэтому исправлять найденные дефекты не на что опереться: непонятно, какое поведение намеренное, а какое случайное. Нужна базовая (baseline) спецификация текущего намеренного поведения. От неё будут отталкиваться последующие изменения-исправления.

## What Changes

- Вводятся 7 базовых capability, описывающих **намеренное** поведение бота в его текущем виде. Код не меняется.
- Принцип отбора требований: baseline описывает только то поведение, которое признано намеренным. Там, где текущее поведение признано дефектом, baseline **молчит**. Нужное требование принесёт отдельный change-исправление (ADDED/MODIFIED).
- Явно признаны намеренными и включены в baseline:
  - каждая озвучка серии — отдельное уведомление;
  - уведомления рассылаются независимо от статуса «завершён»;
  - /mysubs показывает в том числе завершённые тайтлы;
  - входящие сообщения, накопившиеся во время простоя, при старте отбрасываются.
- Сознательно не описаны (будущие changes): изоляция ошибок фоновых циклов, повторная доставка уведомлений, поведение при первом запуске с пустым хранилищем, привязка подписки к карточке, целостность подписок, ответы на нажатия кнопок, пустой список подписок, разбор эпизодов без поля или с одиночным значением, выбор сезона, обновление известных тайтлов, ранжирование поиска, неожиданный ввод в поиске, сброс сценария по /start, формат счётчика страниц, косметика текстов.

## Capabilities

### New Capabilities

- `bot-onboarding`: точка входа: /start с регистрацией пользователя, /help, меню команд, реакция на сообщения вне сценариев.
- `title-catalog`: какие тайтлы известны боту и как меняется их состояние (вышедшие серии, всего серий, «завершён»); синхронизация с AnimeGo.
- `title-browsing`: просмотр незавершённых тайтлов каруселью по команде /choose.
- `title-search`: нечёткий поиск незавершённого тайтла по названию по команде /search.
- `subscriptions`: подписка на тайтл из карточки, просмотр подписок и отписка через /mysubs.
- `episode-notifications`: обнаружение новых серий на AnimeGo и рассылка уведомлений подписчикам.
- `bot-runtime`: техническое поведение процесса: совместная работа бота и фоновых циклов, конфигурация, поведение при перезапуске.

### Modified Capabilities

Нет: в проекте пока нет спецификаций.

## Impact

- Код, API и зависимости не затрагиваются.
- Появляется `openspec/specs/` с 7 спецификациями после архивации этого change.
- Последующие changes-исправления будут добавлять требования в эти capability.
